# Custom-taxonomy configurations

The runnable example for training on your own categories is in
[`examples/custom_training/`](../../examples/custom_training/):

- taxonomy;
- data recipe;
- SFT, ATPO-G, and ATPO-C configs;
- a synthetic data generator.

Copy that directory next to your data and adapt it. The walkthrough is
[docs/custom_training.md](../../docs/custom_training.md).
